# Clothing catalog (Next.js + Supabase)
1. Supabase: run `supabase/schema.sql` in SQL Editor.
2. Copy `.env.example` to `.env.local` and fill the two values (Project Settings > API).
3. `npm install` then `npm run dev`.
4. Open `/admin/login`, create an account, create the shop. The shop page is `/your-slug`.
5. Vercel: import the GitHub repo, add the same two env variables, Deploy.
